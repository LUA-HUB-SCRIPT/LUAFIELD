# 🌌 LuaField UI Framework v1.0

**LuaField** is a modern, lightweight, and modular UI Library designed for Roblox Executors. Forked and re-engineered from the Rayfield Suite, it offers faster execution performance, a clean 6-file modular structure, and highly customizable theme palettes.

---

## 📁 Directory Structure

```text
LuaField/
├── init.lua          <-- Main Loader (Entry Point)
├── Core.lua          <-- Window Management & Keybind Loop
├── Components.lua    <-- UI Elements (Button, Toggle, Slider, Input)
├── Themes.lua        <-- Theme Manager & Color Palettes
├── Config.lua        <-- Auto Save/Load System (.lfield)
└── Utilities.lua     <-- Helper Tools (Tweening, Dragging, Safe CoreGui)
